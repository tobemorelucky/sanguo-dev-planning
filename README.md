# 汉末山河 · 开发规划

一款以东汉末年为背景的单机历史策略游戏。玩家在统一时间轴上处理城市治理、人物任命、军令和情报。

## 当前进度

- 八城区域已完成试玩验证，八城地图及墨青古铜界面已通过阶段性美术验收。
- Core 的兖州扩展候选等待人工验收。全国城池与道路仍用于地图展示与未来规划。
- 全国二维舆图使用连续缩放，区域图用于操作，天下总览提供地理和局势背景。V30-A 已通过技术验证，等待人工美术验收。
- 当前以 Unity 6.3 LTS 作为客户端，使用独立的纯 C# 模拟核心。

## 下一轮讨论

- 八城已经验证的玩法如何逐步扩到更大区域。
- 全国总览与各区域的地图可读性、城池识别和信息层级。
- 哪些城市和路线值得纳入下一轮可玩范围，以及对应的验收标准。
